# Rem 用户指南

> **版本状态**：内置查看器（下面「打开文件」一节）方向已确认但**尚未实现**。当前版本点击图片或视频仍然是交给系统应用打开，其余章节描述的是已经可用的行为。

## 接入 Library

1. 打开 Rem，点「接入 Library」。
2. 在系统文件选择器里选中包含 `相册/` 和 `画集/` 的文件夹。
3. Rem 立即显示上次的缓存，然后在后台核对有没有新增或改动过的文件。顶部进度条消失表示核对完成。

顶栏右侧的按钮：

- 感叹号：列出不符合文件规范的内容，只报告，不会自动改动文件。
- 刷新：重新核对整个 Library。
- 菜单：更换或断开 Library。

## 浏览相册

- 按拍摄时间从新到旧排列；文件没有拍摄时间时用修改时间。
- 顶部「全部 / 图片 / 视频」切换显示范围。
- 拖动右侧滑块可以快速定位，拖动时会显示当前位置的时间和地点。

## 浏览画集

- 默认列出所有 `作者名称-项目名称`，按作者再按项目名称排序。
- 搜索框对作者名称和项目名称做最小匹配，输入的内容出现在名称任意位置即可，例如 `cde` 能匹配 `abcdef` 和 `abcde`。
- 点进项目后按序号浏览，右侧滑块显示当前序号。

## 打开文件（尚未实现）

以下是已确认的设计，**当前版本还没有**：

- 点任意图片或视频，直接在 Rem 里查看或播放，不会跳出应用。
- 查看器里左右滑动可以连续切换同一列表中的上一个或下一个媒体，图片和视频混在一起也能连续浏览。
- 图片支持双指缩放、拖动平移和双击放大/还原。未放大时单指左右滑动翻页；放大后单指滑动是移动图片，不会误翻页。
- 视频在应用内播放，可以播放/暂停和拖动进度。
- 视频播放时切到别的媒体或按 Home 回到后台，声音会立即停止，不会在后台继续响；回到该视频时停在上次的位置，但保持暂停，不会自动播放。
- Rem 不记录你看到哪里，关闭查看器或退出应用后不保留观看位置。
- 想用别的应用打开时，用查看器里的「用其他应用打开」。
- 文件格式不被支持或解码失败时，Rem 会明确提示，并让你用其他应用打开，不会闪退或黑屏。

已实测的格式边界：

- 常见格式（MP4、MOV、MKV、WebM、TS、3GP、AVI 等）可以在 Rem 内播放并拖动进度。
- FLV 可以播放，但进度条拖不动，这是格式本身的限制。
- WMV 无法在 Rem 内播放，Rem 会提示并让你交给其他应用。

## 设置

- 「从系统相册隐藏」开关在 Library 根目录创建或移除 `.nomedia`，用来阻止后续媒体扫描把 Library 里的内容收进系统相册。开关状态直接来自 Library 里有没有这个文件，换设备或手动删掉文件后状态会跟着变。
- 关闭开关只移除 `.nomedia`，不会恢复或删除任何媒体。
- 已经进入系统相册的内容不会立刻消失：系统需要重新扫描才会按新状态更新，Rem 不主动触发扫描。

## 不会改动你的文件

- Rem 只读取 `相册/` 和 `画集/` 的直属文件，不进入更深的层级，也不读取 `待分类/`。
- Rem 不会改名、移动、删除、覆盖或编辑任何媒体文件。
- Rem 只在自己的内部目录 `.gallery/` 下写入两个文件：`RULES.md`（文件模式说明）和 `index.json`（可删除的扫描缓存）。
- 唯一的例外是上面那个开关写入的 Library 根目录 `.nomedia`；它是一个空的控制标记，不是媒体文件。除此之外 Rem 不写 Library 的任何位置。
- 实际整理文件请依据 `.gallery/RULES.md` 由人完成。

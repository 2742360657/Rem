# Rem 用户指南

当前版本只支持以下最小流程：

1. 用户显式选择或接入一个 Library。
2. Rem 读取 `相册/` 和 `画集/` 的规定层级。
3. 在相册中按媒体拍摄时间浏览；没有拍摄时间时使用文件修改时间。地点只在媒体有 GPS 或地点元数据时显示。
4. 在画集中按作者名称或项目名称进行最小字符串匹配，进入项目后按四位序号浏览媒体。
5. 图片和视频可以混合查看，也可以分别筛选；长列表可以拖动右侧滑块快速定位。
6. 打开图片或视频时优先调用系统查看器或播放器。

`待分类/` 当前不会被读取或展示。当前版本不会改名、移动、删除、覆盖或编辑任何底层文件，也不会自动全盘扫描。

# Gallery 使用说明

## 首次使用

1. 点击“选择文件夹”，通过 Android 系统目录选择器选择一个空目录或已有媒体目录。
2. Gallery 会创建 `.gallery/`、`GALLERY_LIBRARY.md`、`.nomedia` 和 Schema v3；原媒体内容不会被改写。`.nomedia` 只阻止系统相册重复收录 Library 副本，不影响 Gallery 扫描。旧 Library 会在接入或扫描时先备份元数据，再做兼容升级。
3. 扫描可识别 `JM/<数字 ID>/`、EhViewer 的 `<gid>-<title>/.ehviewer` 和 Pixiv 的 `<illust_id>_pN` / `_ugoira…`。识别只读取目录与文件名，不需要站点账号。
4. 扫描完成后，新发现内容进入 Inbox。`Photos/` 始终按相册媒体扫描，`Images/`、`Videos/` 是按真实目录浏览的普通分类媒体；`ImageSets/` 中的多图目录或 ZIP/CBZ 会成为漫画候选，动漫与影视视频推荐放在 `Anime/`、`Movies/`、`Series/` 或 `Works/`。旧 Library 的普通多图叶子目录仍会兼容识别为 ImageSet。
5. 在详情页编辑标题、作者、标签、Collection 和 Series。保存后这些信息写入 Library，而不是只留在手机数据库中。
6. 人工修改过的元数据字段会在便携目录中标记为 `manual`，以后增加自动识别或在线元数据刷新时不得覆盖这些字段。
7. 当前版本不在 App 内抓取站点。以后需要同步 JM、EhViewer/E-Hentai 或 Pixiv 的标题、作者和标签时，可让 Agent 先阅读 Library 根目录的 `GALLERY_LIBRARY.md` 再按来源 ID 辅助整理；Agent 只能更新未标记为 `manual` 的字段。标签采用整组字段锁定，人工改过标签后 Agent 不得擅自追加或改写。

## 阅读与播放

- 独立图片支持缩放和平移。
- 在“相册”或“图片”中打开单张媒体后，可在当前时间线内左右滑动连续浏览；双指缩放后单指用于平移，回到原始比例后恢复翻页。
- 从搜索、作者、标签或 Collection 结果打开时，左右滑动只浏览当前结果集，不会突然跳到无关媒体。
- 点按漫画先进入作品详情页，可检查封面、作者、Tag、路径和阅读进度，再选择“开始/继续阅读”；编辑不会打断列表浏览。
- 漫画/ImageSet 使用黑底沉浸式纵向连续阅读；轻触页面可呼出控件，长按当前页打开页操作侧栏，双指缩放后可单指平移，阅读位置随 Library 保存。
- 阅读器会按滑动方向预载前方 5 页、保留后方 2 页，并使用可自动清理的本机缓存；快速跳页会取消已经过时的预载任务。目录漫画按屏幕阅读所需尺寸解码，ZIP/CBZ 的已解码页面也会短期缓存。缓存可以从 Android 的应用存储设置中安全清除，不会删除 Library、标签或阅读进度。
- 目录型漫画可在阅读页打开“调整页序”：可看缩略图上/下移动，或指定目标页码。确认“保存并编号”后，底层图片按当前顺序重命名为连续页码；应用会写入可恢复事务，异常中断或下次扫描时会回滚。ZIP/CBZ 为只读，不直接改写压缩包。
- 本地视频使用 Media3 播放，退出详情页时保存播放位置。
- 相册视图混排照片、视频和已配对的 Live/Motion Photo，并优先使用 EXIF/视频拍摄时间。

## 返回与退出

- 系统返回键/返回手势与顶部返回箭头一致：先关闭右侧工具栏、对话框或选择态；阅读器返回作品详情，作品详情再返回作品列表。
- 首页第一次返回会提示“再按一次返回退出 Gallery”，两秒内再次返回才退出。
- 每个 Library 的一级页面状态会分别保留；“图片 / 视频”还会分别记住上次浏览的真实目录。当前一级页面、搜索词和详情项目会在常规配置变化或系统回收进程后恢复；主动退出后仍从首页进入。

## 文件安全

- “移入回收站”只隐藏项目并写逻辑标记，不移动真实文件。
- 回收站保留原媒体缩略图（包括目录漫画封面和压缩漫画首图），方便确认后恢复；不会因为预览而恢复或改动文件。
- “永久删除”才会删除媒体；执行前会重新检查路径和内容大小。
- “整理文件”必须先生成计划。目标冲突会阻止执行；确认后会备份元数据、写事务日志、复制、校验，再删除源文件。
- 移动介质中途断开后，重新接入同一 Library 会恢复已确认但未完成的 Organizer 事务。
- “检测重复内容”只展示 SHA-256 相同的文件，不自动去重。

## 导入与派生

- “系统相册”支持 Android 的完整或部分照片授权；拒绝广泛授权后仍可使用系统选择器。
- 导入为相册媒体时保持原字节不变，并保留 `DCIM/Camera`、`Pictures/Screenshots` 等来源层级放入 `Photos/`。
- 仅选择图片或仅选择视频时，还可分别“按来源分类”导入到 `Images/` 或 `Videos/`；来源目录会成为默认的文件夹式分类视图，之后可在元数据中追加或改为虚拟 Collection，不会为了分类移动文件。
- 在系统相册按一个来源文件夹筛选后，点击“全选当前”，即可把该文件夹整组导入为图片或视频分类。
- 选择至少两张图片时可以显式导入为 ImageSet；页面按自然文件名排序复制到 `ImageSets/Imported/`。
- 系统相册导入始终复制，不移动、不删除手机相册原文件。
- 如果已经误导入为相册媒体，可在“相册”中选择图片并显式派生 ImageSet；该操作复制页面，不会删除原相册媒体。
- 详情页的复制按钮可以把照片或漫画指定页派生成普通图片。
- 图片页可选择至少两张独立图片，复制组成新的 ImageSet。
- 派生内容与来源彼此独立；删除来源不会级联删除派生项。

## 相册批量操作

- 相册使用紧凑缩略图网格。点按打开，长按任意项目先显示查看、编辑、收藏、派生、回收站和进入多选等快捷操作；也可点击“选择”直接进入多选。
- 多选后可全选、批量收藏/取消收藏、追加作者/Tag/Collection、把多张照片派生为 ImageSet，或移入逻辑回收站。
- 批量元数据是“追加”语义，不会覆盖各项目已有的作者/Tag/Collection；批量回收也不会移动或删除真实文件。

## 三个主视图

- “相册”只显示照片、相册视频与 Live/Motion Photo，按拍摄时间混排，不提供文件夹分类，也不显示作者和 Tag 筛选。
- “相册”的右侧工具栏只提供媒体类型和时间顺序；“图片 / 视频”的右侧工具栏提供当前路径、返回上级和子目录；页面工具不会混进全局左侧“库与管理”。
- “图片 / 视频”按真实文件夹显示目录封面和内容，并分别记住图片与视频所处路径。Collection 不会伪装成目录；直接修改逻辑分类不会移动底层文件。
- “漫画 / 动漫”包含 ImageSet 与作品视频；作者、Tag、Series、搜索和排序平时隐藏在页面右侧工具栏中。普通视频可在元数据编辑器中切换到作品库，或切回分类视频。
- 漫画的最小单位是一本 ImageSet；普通图片是单文件。两者之间通过显式派生/复制转换，互不混淆也不会自动删除来源。

扫描器兼容常见下载结构，包括“作者/NO.序号 作品名[页数-体积]/001.jpg”、漫画“系列/Chapter 01/页面”、动漫 `S01E02` 文件名以及图片目录中的附带视频。解析结果只是建议，人工元数据始终优先。

## 多 Library

可接入多个 Library，并从顶部切换。搜索默认聚合所有在线 Library；离线介质保留索引并显示离线，不会被当成已经删除。

“移除登记”需要确认，只清除本机索引并释放 Android 目录授权，不删除媒体或 `.gallery` 便携元数据。

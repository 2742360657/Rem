# Temporary handoffs

只有跨会话或明确交给另一个 Agent 的未完成任务才在这里建 `<task-id>.md`。

任务完成后删除 handoff，并把长期结论写回对应权威文档。
不要把这个目录当第二份 DEV_LOG 或 STATUS。

并行任务也在此登记文件归属；同一文件同一时间只有一个写入者。每个任务使用以下字段，小任务可压缩，但不可省略归属与验证证据：

```text
需求编号 / 目标 / 非目标：
基线提交与未提交修改：
主负责人：
子任务、执行者、唯一拥有文件：
共享接口与依赖：
便携数据影响：
已作决定及理由：
已完成、验证命令与结果：
不要重复的工作：
剩余工作与验收条件：
已知风险：
最后更新时间：
```

主 Agent 统一回写权威文档和最终状态。接手前核对实际 Git 状态；不能用旧交接覆盖新规范。完成后删除任务文件，保留本 README。
